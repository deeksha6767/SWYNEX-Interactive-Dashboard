# SWYNEX Interactive Dashboard – Task 3

## Project Overview
This project presents an interactive Power BI dashboard built using the NYC Airbnb dataset as part of the SWYNEX Data Analyst Internship.

## Tools Used
- Power BI
- Power Query
- Data Visualization

## Dashboard Highlights
- Total Listings
- Average Listing Price
- Average Reviews per Month
- Highest Listing Price
- Listings by Room Type
- Average Price by Room Type
- Listings by Neighbourhood Group
- Average Reviews by Neighbourhood Group
- Price Distribution for Listings Under $500

## Objective
To analyze Airbnb listing data and present useful insights about pricing, room types, neighbourhoods, and reviews through an interactive dashboard.
